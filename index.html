LUMA WINDOWS DESKTOP - PRIVACY INFORMATION Prepared October 8, 2026; applies to the standalone 0.6.2 Windows package.

The standalone game runs locally. It has no player accounts, advertising SDK, analytics SDK, in-game purchases or automatic upload of player information. The game does not send progress, arrangements or gameplay events to a server.

The game stores completed chamber identifiers, optional Mastery, the resume chamber and sound preference in its local application-data folder. If you choose Save setup, it also stores your Open Lab arrangement there. Backups and logs may remain in that folder. These files are not uploaded by the game. The Windows folder is: %APPDATA%\Godot\app_userdata\Luma — A Little Lightwork To remove them, close every running game instance, back up anything you want to keep and delete the Luma application-data folder described in README.txt. Deleting the extracted game folder alone does not delete saved progress.

Desktop save coordination binds a local loopback socket to prevent concurrent writes. It accepts no connections and transmits no data over that socket.

If you choose to send a bug report, you control which screenshots, logs or save files you share. Review them before sending. The publisher's handling of support messages and any storefront's own data practices are separate from the game. Email info@synapse-one.com for privacy or support questions. Support messages are used to answer your request and investigate reported issues. Do not send passwords, payment credentials or unrelated personal files. For questions or deletion requests about information you voluntarily sent, contact the same address and identify your original request.

This information does not describe the Android Play build or any future account, cloud, analytics, advertising or platform integration.
